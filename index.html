Hello from GitHub Actions! Version 3

This page is one file in a GitHub repository. Every time that file changes on main, GitHub Actions copies it to an S3 bucket and the site you are reading updates.

  1. GitHub You edit index.html and commit to main.
  3. GitHub Actions Checks that the file exists, then signs in to AWS.
  5. S3 bucket Receives the new index.html and serves it here.
